# CLAUDE.md - Project Rules

## Golden Rules

1. **Language for conversation**: All conversations and explanations with the user must be in **Portuguese**.

2. **Language for code**: All code, variables, comments, tests, and commit messages (git commit) MUST be strictly in **English**.

3. **TDD**: Follow Test-Driven Development rigorously.
   - Write tests first (Red)
   - Make tests pass (Green)
   - Refactor (Refactor)
   - Never write implementation without a failing test first
